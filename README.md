# CogTrace 齿盘核查台

在正面齿盘照片上查看齿缘像素、径向剖面和整周半径，保留检查时使用的原片。原片向右是 0°，角度在画面中顺时针增加。浅色背景、暗色齿盘适合当前按亮度找边方式。

1. 打开明确标为合成的练习，或导入单张 PNG、JPEG、TIFF、BMP 或 WebP。
2. 设置盘心、内外半径和金属亮度上限。原片点读显示亮度、距盘心半径、方向；取「选方向」可把角度填到当前核查。
3. 保存并核查，显示环带内该径线最外实测暗像素、实际源坐标，和手填齿数对应的简单角距。可查看一圈半径或当前径线。
4. 双齿对照时，先用「选方向」记录完好齿并点「先记完好齿」，再点选待查齿方向并「再记待查齿并试算」。两枚齿都只取各自选角 ± 半个手填齿距的扇段；自动角偏限制在 ±1/4 齿距，也可手填后采用。对照只使用同一角偏下两边都有实拍边读数的角度，缺读数的一格留空且不计少料；正的半径差才标记少料。点对照表中的角度后，会列出两边各自的实际源角、源像素和半径，`PNG 校样` 同时画出两处源点。
5. 需要交接时可下载径线 CSV、原片标注 PNG、核查 ZIP，或把原照送入准备工程。

常用只读接口：`GET /cogtrace/cards/<id>/compare?reference_angle=0&suspect_angle=45[&offset=0][&comparison_angle=-3]`；`/measurement` 和 `/export/proof.png` 接受同样的对照参数。不传对照参数时，原有单角核查和校样保持不变。

`docker compose up --build -d --wait` 默认本机端口 19914。可使用 Python 3.11 虚拟环境安装 `requirements.txt`，然后执行 `./start.sh`。应用数据保存在独立卷或普通启动的本地数据目录。
